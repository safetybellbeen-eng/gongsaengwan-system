03

경기장 지도 (네이버 지도)

경기장을 목록에서 고르거나 이름을 입력하고 "조회"를 누르면 위치를 확인할 수 있습니다.
(경기에 확정 반영되는 공식 경기장은 관리자가 관리자 도구에서 지정합니다)
⚽ 플랩풋볼에서 서울 지역 경기 찾아보기 ↗
경기장을 선택하거나 검색하면 지도에 핀이 표시됩니다.
목록에 있는 경기장은 정확한 주소로, 그 외에는 입력한 이름으로 지도에서 검색해 표시됩니다.
네이버 지도를 불러오지 못했어요
이 Client ID는 네이버클라우드플랫폼에 등록된 주소(http://localhost:5500, http://127.0.0.1:5500)에서 열었을 때만 지도가 표시됩니다.
지금 이 파일을 다른 방식(로컬 더블클릭, 다른 포트, 다른 도메인)으로 열었다면 그것이 원인입니다.
해결하려면: ① 이 파일을 5500 포트의 로컬 서버(예: VS Code Live Server)로 열거나, ② console.ncloud.com에서 실제 배포 주소를 Web 서비스 URL에 추가로 등록해 주시기 바랍니다.

공지사항 관리

기상청 API 키 설정

지금까지 날씨는 Open-Meteo(해외 예보 모델)를 사용해서 실제 기상청 수치와 다를 수 있습니다.
아래에 기상청 API 키를 등록하면 오늘~모레 예보는 실제 기상청 단기예보 데이터로 표시됩니다(그 이후 날짜는 아직 Open-Meteo로 보완됩니다).
키 발급: data.go.kr "기상청_단기예보 조회서비스"에서 무료 활용신청 → "일반 인증키(Decoding)"를 그대로 복사하여 붙여넣으시기 바랍니다.
